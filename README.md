A browser-based action RPG that teaches machine learning to beginners. Players battle monsters that represent ML algorithms, ask a live Gemini-powered tutor questions mid-battle, and write Python code spells that run directly in the browser.

- **Gemini integration:** Live tutor, battle narration, code evaluation and per-blank adaptive hints
- **Curriculum:** 6 zones from Linear Regression to Self-Attention, with flashcards, battles and a code lab in each mission

- **Stack:** React, TypeScript, Vite, Tailwind CSS, Gemini API, Pyodide, Monaco Editor, Plotly.js, Firebase

### 💬 [Feedback-Sensitive Emotional Support Chatbot](https://github.com/Chetan10R15/ML-Project-12341750-DSL501)
`AI Engineer` `Data Analyst`

An ML course project (DSL501) that extends the PAL persona-aware emotional-support model so it can detect and respond to user feedback such as corrections, preferences and dissatisfaction.

- **Approach:** A feedback detector plus a feedback-aware dialogue model with dynamic persona memory, compared against a baseline PAL model
- **Evaluation:** New metrics (FUR, CIL, DRR) and a visualisation suite comparing the models
- **Demo:** Interactive command-line demos and a Streamlit chat app
- **Stack:** Python, PyTorch, Transformers, Pandas, Matplotlib, Seaborn, Streamlit

### 🤖 [Autonomous Garbage-Collecting Robot](https://github.com/Chetan10R15/story)
`AI Engineer` `SDE`

- **Perception:** YOLOv8 detection on Picamera2 frames
- **Control:** Motor control through GPIO with PWM, a search, align and approach loop, and a return-to-bin routine
- **Stack:** Python, Ultralytics YOLO, Raspberry Pi, GPIO
